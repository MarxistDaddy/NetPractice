### Description 

The objective of NetPractice is to provide a basic understanding of how networking and the internet work in general.

This Project comes with 10 hands-on configuration exercises that help you understand how IP addresses, subnetting work. And how to manage and connect networks to the internet and vice versa.

### Instruction

This project comes with a script that, upon running, launches a webpage on default browser. In which you will have to enter your username and start solving the exercises 

To run the training interface, run the provided shell script:

```bash
    ./run.sh
```

This scripts starts the training and the exam interface on the web

In case the web page does not open in your browser.
worry no more brotha... :D

Try to change the default browser to a different one. 

Else, copy the IP address in the said script and past it in the browser. the webpage is hosted on local host.
